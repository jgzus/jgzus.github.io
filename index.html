About

I'm JGZUS. I'm learning web development and blockchain development together: how to build a page, and how that page can work with a smart contract.

This site is the first thing I'm publishing. It is a place to practice the basics in the open and to keep later work in one list — contracts on testnets, small dApps, and the tools around them.

There is no framework and no build step. The files in the repository are the files the browser loads. That is on purpose, so the project stays readable while I'm learning.
